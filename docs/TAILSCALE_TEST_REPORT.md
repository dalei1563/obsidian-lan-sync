# Tailscale 跨主机验证记录（0.3.1）

日期：2026-11-08（北京时间）。在用户授权的独立测试主机上部署，测试地址和认证信息不写入公开仓库。

## 环境与隔离

- 服务端：Ubuntu 24.04.4 LTS、Docker 29.6.2、Compose 5.3.1，真实默认 bridge 网络。
- 服务仅绑定测试主机的 Tailscale IPv4 地址和独立端口，CouchDB 不发布端口。
- 两个独立 bind 数据目录，运行中 inspect 已确认挂载；不接入原生产笔记库。
- 自研网关从 GHCR 0.3.0 升级到 0.3.1，CouchDB 3.5.3。独立 Compose 项目，主机原有应用保持运行。
- Windows Obsidian 独立配置和笔记库。安装器 1.12.7，运行日志显示应用载入已下载的 1.15.0 包；实际启用插件 0.3.1。

## 修复与验证

旧版安装器没有把 Tailscale 使用的 100.64.0.0/10 纳入代理绕过范围。对安装子进程设置一个不可用代理后，0.3.0 实际生成的命令无法下载安装插件。

0.3.1 对 CLI 生成的 Windows/macOS 下载命令，以及 PowerShell/Bash 资源下载器补齐该范围。使用相同不可用代理重新执行服务端生成的一行 Windows 命令，插件安装成功。没有修改用户系统全局代理配置。

回归覆盖该范围两端和相邻公网段、类似域名，确保不把整个 100.0.0.0/8 都绕过代理。最终本地 48 项测试：40 项通过、8 项按环境跳过；[0.3.1 远端 CI](https://github.com/dalei1563/obsidian-lan-sync/actions/runs/42469254188) 与 [镜像发布](https://github.com/dalei1563/obsidian-lan-sync/actions/runs/42469254206) 成功。

## 两客户端核心同步测试

两个隔离的客户端使用本项目 Engine，通过 Tailscale HTTP 访问真实 Docker 后端；本地文件适配为受控内存模型，状态另行序列化，不冒充两台实际 Obsidian GUI。

全部六组通过：

1. 中文、BOM、CRLF、空笔记原始字节往返一致，不重复上传。
2. 两个方向修改和新增均能同步。
3. 改名保留逻辑文件 ID。
4. 删除传播，不影响其他笔记。
5. 离线并发修改保留两个版本，明确选择后收敛。
6. 从已保存状态重建客户端，不产生重复修订。

后端从 0.3.0 升级到 0.3.1，再停止/启动网关和 CouchDB：原设备令牌、serverId、业务修订和原始正文哈希均保留；客户端检测新 epoch 后重新核对并同步成功。

## 真实 Windows Obsidian

- 执行服务器生成的 Windows 命令，将已发布插件安装到隔离测试库。
- 启用后自动读取 bootstrap，确认 HTTP 提示，出现首次同步预览：本地 3 篇、远端 1 篇。
- 点击首次确认，上传和下载成功，自动同步开启。
- 第二客户端修改远端笔记，Obsidian 收到更新；通过 Obsidian Vault API 修改本地笔记后，第二客户端收到相同正文。
- 普通 LF 文件在编辑器打开期间，远端修改不会覆盖本地；关闭该标签并同步后，收到远端新版本。
- 同步冲突界面可展示两个版本；明确选择远端分支后收敛为单头，历史保留。
- 服务完整重启后，Obsidian 仍显示“已同步”，pending=0、issues 为空。
- 临时诊断包装已撤销，最终插件 main.js SHA-256 与服务器分发的发布文件一致；最终 dev:errors 和错误级控制台均无错误。

## 观察到的行为与限制

- Obsidian 打开 BOM/CRLF 样本时，本次环境把磁盘正文规范化为无 BOM 的 LF。这会被视为一次本地字节修改；若另一端也在修改，就会出现需要选择的冲突。传输前后原始字节一致与“编辑器不改变文件格式”是两件事。测试确认双方版本保留，明确选择后可继续同步。
- 测试过程中 CLI 一度无响应，清理隔离配置的遗留测试进程并重新加载后恢复。没有据此修改产品逻辑；若复现应继续调查。
- 本次为功能和恢复测试，未完成大型库、持续运行或吞吐量压力测试。
- 该测试主机是 Ubuntu，不代表 Rocky Linux 的 SELinux enforcing 已验收。原 Rocky Linux 部署未在本轮迁移或升级。
- macOS 的安装和构建通过 CI，当前跨主机 GUI 验证使用 Windows。

测试服务保留运行以便继续验收。实际测试地址、生成邀请命令及截图保存在本地受控测试目录，未写入公开镜像、源码或本报告。
