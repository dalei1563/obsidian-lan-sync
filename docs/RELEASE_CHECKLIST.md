# LAN Note Sync 发布前验收清单

本清单针对 `chore/lan-hardening` 的 0.5.0 代码和 2026-11-10 本机记录，不是发布批准。路线仅限 LAN；飞书方案已废弃。完成下列真实数据库及实机项前，不能据此宣称当前分支已完成生产验收。任何真实 CouchDB 行为结论，当前均**未在真实 CouchDB 上验证**。

## ① 已在本机自动化验证

- [x] Windows、Node.js 24.15.0：`npm.cmd test` 共 **129 项，117 通过、0 失败、12 跳过**；`npm.cmd run build` 成功且未报告 warning。证据：[加固基线](LAN_HARDENING_BASELINE.md)。此结果是阶段 2 完成时的记录，不代表后续代码提交自动通过。
- [x] 本地 SQLite、HTTP 及内存 Vault：覆盖并发冲突、覆盖预览变化、批量删除确认变化、空文件、超过 5 MiB 文件拒绝、离线队列及故障注入恢复。不是跨设备 Obsidian 文件系统实测，**未在真实 CouchDB 上验证**。
- [x] 模拟网络错误、鉴权失败、文件占用、磁盘状态写入失败；验证手动提示、待处理项及重试。不是实际磁盘满或操作系统文件锁测试，**未在真实 CouchDB 上验证**。
- [x] 本机测试未配对拒绝、配对限流、撤销及跨仓库隔离、协议不兼容停止、本机快照清理预览确认和旧状态版本保护；容量数值是逻辑统计，**未在真实 CouchDB 上验证**。
- [x] Windows 和 Bash 安装器自动化。符号链接用例实际尝试创建时返回 `EPERM`，列入 12 项跳过；未将其计作通过。
- [ ] 发布候选最终提交重新执行 `npm ci`、`npm test`、`npm run build`，记录 OS、Node、提交、完整通过/失败/跳过数与构建结果；任何失败或未解释的跳过先处理。

## ② 需要真实 CouchDB

**当前加固分支未在真实 CouchDB 上验证。** 不用生产数据、生产数据库或生产凭据。测试会创建并删除随机测试数据库，须使用专用隔离实例。

- [ ] 在可用 Docker 的隔离 Linux 测试环境使用 CouchDB 3.5.3、回环端口和临时卷，按[加固基线](LAN_HARDENING_BASELINE.md#在隔离-linux-docker-环境验证-couchdb)运行 `npm run test:couch`，保存版本、提交、日志和汇总；确认原先跳过的 8 项 CouchDB 同步及 3 项 CouchDB 管理测试实际执行并通过。
- [ ] 针对当前分支核实幂等重试、设备撤销、并发修订、分页、历史与整库恢复、压缩后的业务历史、单网关所有权；额外验证加固后的协议检查、容量采样和配对限流在真实 CouchDB 网关上工作。
- [ ] 测试完成只清理本次创建的测试容器、临时卷及随机测试库，保留测试日志；确认没有连接或改动既有生产容器、卷和数据库。
- [ ] 在隔离备份上演练同时恢复 CouchDB 数据、gateway 所有权状态和配置，验证凭证、正文、历史与同步。记录数据量、步骤、结果及恢复点以后的变更如何保全。

## ③ 需要真机或真实环境

- [ ] macOS：使用隔离 Vault 在真实 Obsidian GUI 中验证安装、接入、BOM/CRLF/空文件、打开中的笔记、冲突、删除回收站、升级和恢复；记录系统与 Obsidian 版本。
- [ ] Windows 与 macOS 两台真实设备：覆盖并发编辑、重命名、断网多次编辑、恢复与确认冲突、预览后两端变更、批量删除、5 MiB 边界及大文件拒绝；确认笔记和独立备份完整。
- [ ] Rocky Linux / 1Panel：在指定隔离部署中检查 Compose 项目、持久卷或数据盘、SELinux enforcing、权限、默认 bridge、升级和健康状态；不影响其他服务。
- [ ] 跨机 HTTPS：验证真实证书与域名、根路径转发、Authorization、安装资源、管理后台 Cookie、请求大小和客户端实际同步；不要将内网 HTTP 的测试结果当作 HTTPS 验收。
- [ ] 长期运行：记录多月或有代表性的写入、历史和备份增长、剩余磁盘、内存及重建时间；观察超阈值提示、断网恢复和大历史库性能。系统回收站与服务器实际物理占用另行监测。
- [ ] 强制终止：只在隔离测试进程／服务中，于正文上传、修订提交、收到回执和本地应用等关键阶段终止并重启；核对队列、基线、正文与历史，并保留日志。当前故障注入不能替代实际强杀。
- [ ] 容量和恢复：验证用户确认前不删除快照、确认后的删除范围及不可恢复提示；测试真实磁盘满、文件锁、权限故障，保留独立备份。
- [ ] 符号链接用例在允许创建链接的系统实际通过；Windows 可检查开发者模式或账户权限，Linux 测试机也需执行。
- [ ] 验证旧版插件与新服务、当前插件与旧服务，以及服务／插件升级和回滚；不支持的数据格式不得强行降级。确认发布包、manifest、镜像 tag、部署模板指向同一经过验证的提交，且远端镜像确实已发布。
